# Aldo&Klio Analyzer

Separación de pistas musicales con IA + análisis musical completo.

## Funcionalidades
- Separación de stems: Voz / Batería / Bajo / Guitarra / Piano / Otro
- Detección de tonalidad, BPM, compás, acordes y estructura
- Reproductor integrado con mezclador DAW, metrónomo y piano iluminado
- Soporte MP3, WAV, FLAC, M4A, MP4, MKV, MOV y más

## Stack
Python · Streamlit · Librosa · Demucs · PyTorch · Web Audio API
